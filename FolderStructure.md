# JavaScript Project Folder Structure

## Root Level
- `.git/` - Git repository metadata
- `Fruits.js` - Standalone JavaScript file
- `README.md` - Project documentation

## Directories

### EventDrivenProgramming/
Event-driven programming concepts and implementations:
- `BasicEventDrivenWebPage/` - Basic event-driven webpage examples
- `BasicSyntax/` - JavaScript syntax fundamentals
- `ButtonsAndEvevnts/` - Button event handling examples
- `CustomEvent/` - Custom event creation and handling
- `EventDelegationReview/` - Event delegation techniques
- `EventDrivenApplication/` - Full event-driven applications
- `EventDrivenWebPage/` - Event-driven web page implementations
- `GradeChecker/` - Grade checking application
- `InteractiveCSSChanger/` - Interactive CSS modification examples
  - `traffic-light/` - Traffic light simulation
- `RemovingEventListener/` - Event listener removal examples
- `ThemeSwitcher/` - Theme switching implementations

### Fundamentals/
Core JavaScript fundamentals:
- `API/` - API interaction examples
  - `fetchingAPI/` - Fetch API demonstrations
- `Arrays/` - Array manipulation and methods
- `AsynchronousJavaScript/` - Async JS concepts (promises, async/await)
- `ConditionalStatement/` - If-else, switch statements
- `DOM manipulation/` - Document Object Model interactions
  - `simpleStudentList/` - Simple student list DOM manipulation
  - `studentGreeting/` - Student greeting DOM application
- `ES6Features/` - ECMAScript 6+ features
- `EventHandling&UserInput/` - Event handling and user input
- `Functions/` - Function declaration and usage
- `LogicalOperators/` - AND, OR, NOT operators
- `Loops/` - For, while, do-while loops
- `Objects/` - Object creation and manipulation
- `Variables/` - Variable declarations (let, const, var)
- `modular/` - Modular JavaScript patterns
- `studentRegistrationForm/` - Student registration form application
